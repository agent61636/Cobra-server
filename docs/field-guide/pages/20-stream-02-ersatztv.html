Remember flipping channels and landing on a rerun you hadn't picked? ErsatzTV brings that back. It builds always-on TV channels out of your movies and shows, complete with a schedule, a program guide and commercial breaks from your filler folder.

It doesn't have viewers of its own. ErsatzTV hands Jellyfin two links, a channel list (M3U) and a program guide (XMLTV), and Jellyfin shows the channels under Live TV on every app: Roku, Apple TV, phones, browsers. Tune in and ErsatzTV starts playing that channel's schedule from wherever "now" is, transcoding it live on the Quick Sync GPU.

Both live in the stream pod, so they talk to each other over 127.0.0.1. ErsatzTV answers on port 8409 for the LAN and WireGuard, has no login page at all, and the gate never publishes it. People away from home watch the channels through Jellyfin at tv.songofeo.com instead.

WHERE THE SHOWS COME FROM

        
Media Sources → Jellyfin: ErsatzTV logs into Jellyfin at http://127.0.0.1:8096 with an API key and syncs the Movies and TV libraries, posters and all.

        
Media Sources → Local: a library of type Other Videos on /media/wd1/filler for the break videos.

        
Both containers mount /srv/storage/disks at the same /media path, read-only. So a file path Jellyfin reports is one ErsatzTV can open too. That shared path is the whole trick.

      

      
THE GPU, AGAIN

        
Every channel someone is watching is a live transcode, so ErsatzTV gets the same /dev/dri and keep-groups wiring as Jellyfin. Its FFmpeg profile says: hardware acceleration VAAPI, driver iHD, device /dev/dri/renderD128, H.264 (plays everywhere), 1080p.

WHY RAM?

        
While someone watches, ErsatzTV writes the channel's live video segments to /transcode. That's a 2 GB tmpfs, a folder in RAM, so the constant little writes never wear the SGIN's SSD.

PRO TIP: REAL TV TIMING

        
A Pre-roll filler preset (Mode: Count 1) drops one break before each episode. Add a Pad preset too and ErsatzTV fills each episode out to the next 30-minute mark, so shows start on the hour and half hour like real TV.

      

      
PRO TIP: THEME NIGHTS

        
A smart collection is a saved search that updates itself. genre:comedy today includes the comedy you add next month, with no rebuild of the list.

      

      
PRO TIP: REBUILD

        
Changed a schedule a lot? Playouts → Build again. The guide in Jellyfin catches up on its next refresh, or press Refresh Guide Data yourself.

      

    

    

      
PRO TIP: THE FILLER STASH

        
Old commercials, bumpers, station IDs, trailers: drop them in \\cobra-stream\media\wd1\filler from the-box, subfolders allowed. ErsatzTV, cobra-breaks and Jellyfin's Filler library all use that one folder. Aim for 50+.

JOE SABOTAGE REPORT

      
Footlocker findings from manual 3.8a and the research notes.

    

  

  

    

      
THE OPEN TOWER

        
ErsatzTV has no login screen. Anyone who reaches port 8409 can rewrite every channel.Never give it a gate hostname. nftables keeps 8409 LAN and WireGuard only; remote viewers use Jellyfin's Live TV.

      

      
THE WRONG HOST

        
The M3U and XMLTV buttons in ErsatzTV copy links with whatever address your browser used. Paste 10.6.9.20 or a hostname and Jellyfin goes the long way, or not at all.Replace the host part with 127.0.0.1:8409 before pasting into Jellyfin.

      

      
THE VAAPI HICCUP

        
The manual marks the VAAPI profile "verify": some builds error on it.If channels won't start, try QSV with the same device in the FFmpeg profile.

      

      
THE IMPOSTOR IMAGE

        
Old guides say ghcr.io/ersatztv/ersatztv. The maintained line is ghcr.io/ersatztv/legacy (v26.x). A rewrite, ErsatzTV Next, is still in early testing.Stay on legacy until Next calls itself stable.

      

    

    

      
THE DEAD KEY

        
Delete or recreate the ersatztv API key in Jellyfin and the sync silently stops finding new episodes.New key → ErsatzTV → Media Sources → Jellyfin → paste → Sync.

      

      
THE EMPTY FILLER

        
A channel with a filler preset but an empty or unscanned filler library plays straight through with no breaks, or gaps.Fill wd1/filler, then Media Sources → Local → Scan.

      

      
THE GHOST DRIVE, PART 2

        
Just like Jellyfin, ErsatzTV only sees drives mounted when it started. Replug wd1 and the channels can't open their files.podman pod restart stream, then rescan.

      

      
THE EMPTY GUIDE

        
Channels added in Jellyfin, but the guide shows "no information" for hours.Dashboard → Live TV → Refresh Guide Data after each new channel or playout build.
