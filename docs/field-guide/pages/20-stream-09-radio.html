Meet the DJ who never sleeps. The radio container runs Liquidsoap, a programming language made for radio. Its script, apps/radio/radio.liq, is fifteen lines long: shuffle the music folder, crossfade between songs, never go silent, send it to Icecast.

The container reads the music library read-only, at /media/music, which is dock1a/music on the SGIN, the same folder the Commander's Navidrome reads. It runs the script from /srv/stream/radio/radio.liq (mounted read-only too), encodes MP3 at 192 kb/s, and pushes it to Icecast at 127.0.0.1:8000, mount /stream.

The station's name comes from the environment: RADIO_NAME="Song of Eo Radio". The music folder can be changed the same way with RADIO_MUSIC.


        
CLAUDE-VIPERNo playlists to build, no requests to take, no coffee breaks. Drop a song into the library and it joins the rotation by itself.

STARTING ORDER

        
The DJ needs the tower. With the scripts, radio.sh starts Icecast, waits for port 8000, then starts radio. With Quadlets, radio.container has Requires=icecast.service and After= it, plus Restart=on-failure every 10 seconds, so a radio that started too early just tries again.

      

      
THE ENTRYPOINT

        
The Liquidsoap image needs to be told which program to run. The script mode passes --entrypoint liquidsoap and then /radio/radio.liq. In Quadlet mode, if the log says it can't run /radio/radio.liq as a command, the line must be Exec=liquidsoap /radio/radio.liq.

WHAT IT PLAYS

        
All of dock1a/music: the Commander's and Rachel's music both. Comedy and your recorded sessions live in their own folders, so they never get on the air.

      

      
WHAT IT DOESN'T DO (YET)

        
No station IDs, no requests, no schedule. That's the whole point of the fifteen-line script: easy to read, easy to change. Liquidsoap can do all of those later if the Commander wants them.

      

      
UP-ALL SKIPS IT

        
sgin/up-all.sh runs radio.sh only if /srv/stream/radio/radio.liq exists. No script in place, no radio, and the rest of the pod still starts: "skipping the radio (no ... yet, part 8)".

      

      
NO PORT, NO DATA

        
radio has no port of its own and writes nothing. Its only output goes over 127.0.0.1 to Icecast, inside the pod.

PRO TIP: COPY, THEN EDIT

        
The repo's apps/radio/radio.liq is the original. The live copy is /srv/stream/radio/radio.liq. Edit the live copy, and keep a backup next to it before big changes.

      

      
PRO TIP: CHANGE THE SOUND

        
Longer fades? Change duration=4. in radio.liq. Better quality? Raise bitrate=192, and remember each listener uses more upload. Then restart radio.

THE MISSING SCRIPT

        
radio.sh stops with "radio.liq is missing" if the script isn't in /srv/stream/radio.Copy apps/radio/radio.liq there first, owned by podsvc (part 8.2).

      

      
THE NAMELESS PROGRAM

        
Quadlet with Exec=/radio/radio.liq: the log says it can't run that as a command.Exec=liquidsoap /radio/radio.liq, daemon-reload, restart radio.

      

      
THE WRONG PASSWORD

        
radio and Icecast disagree on the source password: the DJ is refused and the station is dead air.Same secret or value for both, then restart both.

      

    

    

      
THE BAD FILE

        
A broken MP3 in the library could crash a less careful DJ.mksafe plays silence instead and the shuffle moves on. Find the file in the log and fix or remove it on the-box.

      

      
THE PUNCHLINE ON AIR

        
A stand-up album copied into music/ ends up in the rotation.Comedy belongs in dock1a/comedy, which the radio never reads.

      

      
THE GHOST DRIVE

        
dock1a replugged: the DJ shuffles an empty folder and goes quiet.podman pod restart stream.
