Homepage is the island's command console at command.songofeo.com: a dark dashboard with one tile per app, grouped into rows, each tile a link with a little dot that turns red the moment that app stops answering.

It's a single container in the gate pod on 127.0.0.1:3000, behind Authelia's two-factor sign-in. There's no database and no settings screen: the whole dashboard is two YAML text files in /srv/gate/homepage. Edit a file, save, and Homepage redraws by itself.

The name used to be home., then throne.; the Commander settled on command. on 5 November. The research notes add a correction worth repeating: Homepage shows your apps and their status, but it doesn't start, stop or update containers.

TWO FILES

        
settings.yaml is the look: title "Cobra", dark theme, slate color, and how many columns each row gets. services.yaml is the tiles: a name, the link (href), an icon, an optional description and the siteMonitor address to check.

      

      
BACKSTAGE ADDRESSES

        
The link you click is the public name (https://tv.songofeo.com). The dot checks the app's back door directly: http://10.6.9.20:8096 for Jellyfin, http://127.0.0.1:8000 for Paperless. So a dot tests the app itself, not nginx or Authelia.

      

      
ALLOWED HOSTS

        
Homepage only answers requests for the names it's told about: HOMEPAGE_ALLOWED_HOSTS=command.songofeo.com. That stops other sites from loading your dashboard by pointing a different name at it.

      

    

    

      
NO DOT FOR THREE

        
Proxmox, OPNsense and PBS use self-signed certificates, which Homepage's checker rejects. Their tiles are plain links. Uptime Kuma watches them instead, with "ignore TLS errors".

      

      
STARTER FILES

        
The first run of homepage.sh copies the starter settings.yaml and services.yaml from the repo. Later runs see the files are there and keep your edits. The manual's part 5.7 writes the same two files by hand.

      

      
ICONS

        
Names like jellyfin.png come from Homepage's built-in icon set; mdi-trophy is a Material Design icon. No image files to upload.

TIPS & TRICKSPOWER-UPS

  

    

      
PRO TIP: ADD A TILE

        
Copy a line in services.yaml, change the name, link and siteMonitor, save. Homepage picks it up without a restart. Keep the two-space indents: YAML is picky.

      

      
CODES

        GATE · podsvc
        nano /srv/gate/homepage/services.yaml
        podman logs --tail 30 homepage
        A YAML mistake shows up here.
        systemctl --user restart homepage
      

      
PRO TIP: MAKE IT START

        
Set https://command.songofeo.com as the start page in THE-BOX's browser. Every morning starts with a glance at the dots.

      

      
PRO TIP: LIVE NUMBERS

        
Homepage widgets can show Jellyfin's streams, Pi-hole's blocks or Proxmox's load right on a tile. Each needs that app's API key in services.yaml; Homepage's docs list the fields per service.

      

    

    

      
PRO TIP: CONTROL THE PODS

        
Want start, stop and logs buttons? That's Cockpit, not Homepage. The research notes suggest the cockpit-podman package for the Cockpit already on the gate (port 9090, LAN and WireGuard only).

      

      
PRO TIP: BACK UP YOUR EDITS

        
Copy the two files before a big edit. If the page goes blank, put the copy back.

      

      
CODES

        GATE · podsvc
        cp /srv/gate/homepage/services.yaml /srv/gate/homepage/services.yaml.bak
      

      
PRO TIP: RED DOT DRILL

        
A red dot? Click the tile. If the app opens, the dot's address is wrong. If it doesn't, check that app's chapter in this guide.

      

      
PRO TIP: HIGH SCORES

        
The repo's starter file already has the High scores tile (mdi-trophy). It stays red until the hiscore board is running.

      

    

  

  

  
SETTINGS.YAML, DECODED

    
title: Cobra · theme: dark · color: slate · headerStyle: clean

    
layout: Watch & listen { style: row, columns: 4 }

    
title is the browser tab and header. theme and color set the palette. layout gives each row of services.yaml its style and number of columns: add a column if a row wraps awkwardly.

  

  

    
PRO TIP: NEW ROW
A new group in services.yaml becomes a new row. Give it a layout line in settings.yaml to control its columns.

    
PRO TIP: DESCRIPTIONS
A short description under a tile ("LAN/VPN only", "Our podcasts") saves guessing later.

  






  

    

    

      
JOE SABOTAGE REPORT

      
Small traps, but they make the whole dashboard go dark.

    

  

  

    

      
THE WRONG NAME

        
Opening Homepage by any name other than command.songofeo.com (an old home. bookmark, say) gets an error instead of the dashboard.Use command. If you add a name, add it to HOMEPAGE_ALLOWED_HOSTS too.

      

      
THE TAB CHARACTER

        
One tab or a wrong indent in a YAML file and Homepage shows an error instead of tiles.Spaces only. Read podman logs homepage for the line number.

      

      
THE FOREVER-RED DOT

        
Pointing a siteMonitor at a self-signed https address (Proxmox, OPNsense, PBS) keeps that dot red forever.Leave those tiles without a dot and let Uptime Kuma watch them.

      

    

    

      
THE OVERWRITE FEAR

        
Running homepage.sh again does not overwrite your files: it only copies the starters when they're missing. But pasting the manual's 5.7 block again does overwrite.After you've customised, don't re-paste 5.7. Make a .bak first.

      

      
THE LEAKY KEY

        
Widget API keys sit in services.yaml in plain text.Keep the file podsvc-only, and give widgets read-only keys where the app offers them.

      

      
THE "IT'S ALL GREEN" LIE

        
A green dot means the app answered Homepage, from inside the gate. It doesn't prove the public name or the sign-in works.That's what check.sh and Uptime Kuma's public-name monitors are for.

      

    

  

    

    
THE WRONG BACK DOOR

      
A typo in a siteMonitor port (4353 for 4533) paints a healthy app red.Compare with the port list in scripts/podman/sgin/pod.sh and gate/pod.sh.

    

    
THE STALE COPY

      
The copies of the scripts in the project files are older than the repo. Their Homepage starters may miss tiles.The repo is the source of truth.
