Paperless-ngx turns paper into a searchable archive. Drop a PDF or a phone photo of a letter into the scans folder; within a minute Paperless reads the text (OCR), files it, tags it, dates it and removes it from the inbox. Then you find any bill, receipt or manual by typing a word you remember.

It's the biggest app on the gate, and the only one with a crew: Postgres holds the database, Redis carries the to-do list for its background workers, and Paperless itself runs the web page and the workers that read your scans. All three share the gate pod and talk over 127.0.0.1.

The inbox lives on the SGIN, not the gate: dock1a/scans, shared from Windows as \\cobra-stream\scans and mounted on the gate over CIFS at /srv/storage/disks. The archive itself, the originals, the OCR'd copies and the search index, stays on the gate's own disk in /srv/gate/paperless.

WHY POLLING?

        
Normally Paperless notices a new file the instant it lands. Those "a file changed" notifications don't cross an SMB share, so the gate would never hear about it. PAPERLESS_CONSUMER_POLLING=60 makes Paperless simply look in the folder every 60 seconds.

      

      
WHAT A WORKER DOES

        
    
          
  • Reads the text with OCR, so a photo becomes searchable
    • 
          
  • Makes an archive PDF next to your original (both are kept)
    • 
          
  • Guesses a date, a correspondent, a document type and tags, learning from what you've filed before
    • 
          
  • Deletes the file from the inbox once it's safely stored
    • 
        

      

      
THE CREW

        
Postgres stores documents, tags and users. Redis is the queue between the web page and the workers. Paperless's Quadlet Requires= both, so systemd starts them first.

      

    

    

      
PAPERLESS_URL

        
Paperless only trusts requests for the address it's told it lives at. It's https://papers.songofeo.com. The name used to be docs., and the old value was still in the Quadlet on setup night; we fixed it on 6 November.

      

      
WHEN THE SGIN NAPS

        
If the gate boots while the SGIN is off, the inbox folder isn't there and Paperless fails. Restart=on-failure with RestartSec=60 retries every minute until the SGIN is back. Nothing to do by hand.

      

      
TWO LOCKS

        
papers. is an admin room: Authelia wants your password and a TOTP code, from everywhere. Then Paperless shows its own login, for the superuser made with createsuperuser (eels, made on 6 Nov).

      

      
SECRETS

        
The database password and the secret key were generated once. Quadlets: inside paperless.container (mode 600). Scripts: podman secrets.

TIPS & TRICKSPOWER-UPS

  

    
      
PRO TIP: MAIL IN

        
Paperless can check an email inbox and file attachments by itself: Mail, add an account, then a rule (for example "PDFs from the bank, tag bills").

      

      
PRO TIP: ARCHIVE NUMBERS

        
Give paper you keep an archive serial number (ASN), and write it on the original. Paperless finds the digital copy; the number tells you which folder holds the paper.

      

      
PRO TIP: RACHEL'S PAPERS

        
Paperless has users and owners. A second Paperless account can see shared documents but not your private ones. She'd also need Authelia TOTP for papers.

      


      
PRO TIP: THE DROP ZONE

        
On THE-BOX, pin \\cobra-stream\scans to Quick Access in Explorer. Point the scanner's "scan to folder" or your phone's scanner app there too. Anything you drop is filed within a minute.

      

      
PRO TIP: TEACH IT

        
Make a few correspondents (Xfinity, the bank, the doctor) and tags, and correct the first dozen documents. Its auto-matching learns from what you file and gets the next ones right by itself.

      

      
PRO TIP: SEARCH LIKE A SPY

        
The search box reads the OCR'd text, not just titles. Type "warranty" or a model number and Paperless finds the page it's printed on.

      

      
PRO TIP: SAVED VIEWS

        
Save a search (say, tag "taxes" this year) as a view and show it on the dashboard. Tax season becomes one click.

SCANNER SETTINGS THAT WORK

    
300 dpi, grayscale, PDF is the sweet spot: sharp enough for OCR, small enough to keep forever. Multi-page letters go in as one PDF, not a pile of JPGs. Photos from the phone work too; flat, bright and square-on reads best.

  






  

    

    

      
JOE SABOTAGE REPORT

      
The Archive was the trickiest room on setup night. Every one of these happened, or nearly did.

    

  

  

    

      
THE CHOWN DISASTER

        
Re-running the manual's chown -R podsvc: /srv/gate after setup took Postgres's files away from its user (999 inside the container). Paperless crash-looped: could not open file "global/pg_filenode.map": Permission denied.As podsvc: podman unshare chown -R 999:999 /srv/gate/postgres, then restart postgres and paperless.

      

      
THE OLD ADDRESS

        
PAPERLESS_URL still said docs. after the rename to papers., so Paperless distrusted its own address.Set it to https://papers.songofeo.com in paperless.container, daemon-reload, restart.

      

      
THE STACKED FSTAB

        
Running the CIFS mount step more than once left eight copies of the same line in /etc/fstab.Cleaned to one line on 6 Nov (backup /etc/fstab.bak-before-cleanup). The manual's grep -q ... || guard now stops repeats.

      

    

    

      
THE WRONG SAMBA PASSWORD

        
The gate logs in to the SGIN's share as user gate. A wrong password in /root/smb-gate.cred means no inbox at all.On the SGIN, sudo smbpasswd gate sets a new one; put it in the cred file with nano, never on the command line.

      

      
THE IMPATIENT START

        
The first start migrates the database for minutes. Killing it halfway means starting again.Give it a few minutes and follow podman logs -f paperless.

      

      
THE VANISHING INBOX

        
Paperless deletes files from scans after filing them. That's by design, but it surprises people looking for the original there.The original is in Paperless: open the document and download it.

      

    

  

    

    
THE DOUBLE SCAN

      
Drop the same file twice and Paperless refuses the second copy as a duplicate. The file isn't lost, it's just not filed again.Check the log line, then delete the extra copy.

    

    
THE TOTP WALL

      
papers. is an admin room, so even at home it asks for a password and a TOTP code.Register TOTP on THE-BOX first (Authelia's boss page).
