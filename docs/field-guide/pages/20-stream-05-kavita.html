Kavita is the island's comic shop. It shelves your CBZ and CBR comic archives, manga and graphic novels by series, draws the covers, and opens a fast page-turning reader right in the browser, phone or tablet included.

It remembers where each reader stopped in every issue, shows what's next in a series, and speaks OPDS, the common catalog language that many reading apps understand. It reads EPUB and PDF too, so it can double as an e-book reader.

Kavita lives in the stream pod on port 5000. Its database, covers and settings stay in /srv/stream/kavita on the SGIN's SSD; the comics come in read-only from dock1a/comics.

WHAT IT READS

    

      
Comic archives: .cbz (a ZIP of page images) and .cbr (a RAR). CBZ is the friendliest.

      
Books: EPUB and PDF, with a reader for each.

      
Metadata: a ComicInfo.xml inside the archive fills in series, number, writer and summary.

OPDS is a catalog feed that reading apps understand. Each Kavita user finds their own OPDS link in their user settings.

SERIES FOLDERS

        
Kavita groups by series, and it expects the files inside folders under the library root, not loose in it. The safe layout is one folder per series:

        
comics / Series Name / Series Name 001.cbz

        
The folder and file names give Kavita its first guess; a ComicInfo.xml inside the archive, when there is one, gives it the real details.

      

      
THE LIBRARY TYPE MATTERS

        
When you add a library, its type (Comic, Manga, Book and so on) tells Kavita how to read names and how to show the pages. The island's library is Comics, type Comic, on /media/dock1a/comics. Manga could get its own library of type Manga later.

WATCHING FOR NEW ISSUES

        
Kavita watches the library folder and notices new files on its own, and it also rescans on a schedule. Linux limits how many folders one user may watch; part 3.3 raised that limit for podsvc, because Kavita, Jellyfin, ABS and the Navidromes all watch at once.

      

      
THE ADMIN

        
The first visit registers the admin account (the email can be anything local). After that, the admin adds or invites one user per reader.

PRO TIP: CBZ IS KING

        
A CBZ is just a ZIP of page images renamed. Scans of your own comics can be zipped up on the-box and renamed .cbz, and Kavita reads them like any other issue.

      

      
PRO TIP: READING APPS

        
Kavita's web reader works well on phones and tablets. For a dedicated app, look for one that supports OPDS; Kavita gives each user an OPDS link in their settings.

      

      
PRO TIP: READING LISTS

        
Crossovers jump between series. A reading list puts issues from several series in the order you want to read them.

      

    

    

      
PRO TIP: WANT TO READ

        
Mark series as "want to read" and use collections to group them ("Cobra classics", "Rachel's picks"). They're shelves on top of the folders, nothing moves on disk.

      

      
PRO TIP: ADDING ISSUES

        
From the-box, copy into \\cobra-stream\media\dock1a\comics\Series Name\. Kavita picks it up; if you're impatient, the library's Scan button does it now.

THE ADMIN SNATCH

        
Until someone registers, the first visitor gets the admin account.Register from the-box the moment Kavita first starts.

      

      
THE LOOSE ISSUES

        
Archives sitting directly in comics/ with no series folder confuse Kavita's grouping, or get skipped.One folder per series under the library root.

      

      
THE SPLIT SERIES

        
"Batcave 01.cbz", "Bat-Cave #2.cbz" and "batcave_003.cbz" can turn one series into three.Name files the same way, or add a ComicInfo.xml with the series name.

      

      
THE WRONG TYPE

        
A Comic library pointed at manga reads names wrong and turns pages the wrong way round.Manga in its own library of type Manga.

      

    

    

      
THE GHOST DRIVE

        
Replug dock1a while Kavita runs and it scans an empty folder: series vanish from the shelves.podman pod restart stream first, scan after.

      

      
THE READ-ONLY SHELF

        
Kavita can't rename, delete or fix files: the library is mounted read-only.Tidy files on the-box over the share, then scan.

      

      
THE WATCHER CAP

        
Too many apps watching too many folders, and new issues stop showing up until a scheduled scan.Keep part 3.3's /etc/sysctl.d/90-inotify.conf.

      

      
THE PHONE-APP WALL

        
An OPDS app on cellular hits the gate's sign-in page, which it can't show.Turn WireGuard on first; the gate then lets it through to Kavita's own login.
